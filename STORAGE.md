# Архитектура хранения данных

## 📊 Текущая архитектура

### 1. База данных PostgreSQL
- **Где**: Docker volume `postgres_data`
- **Что хранится**:
  - Пользователи
  - Прогресс пользователей
  - История попыток решения заданий
  - Метаданные тем и заданий
- **Почему не в объектном хранилище**: Базы данных требуют ACID-транзакций и реляционной структуры, объектное хранилище для этого не подходит

### 2. Файлы (задания и теория)

#### Вариант A: Объектное хранилище MinIO (по умолчанию) ✅
- **Где**: MinIO bucket `oge-ege-files`
- **Что хранится**:
  - Текстовые файлы с заданиями (`.txt`)
  - PDF файлы с теорией
- **Настройка**: `USE_MINIO=true` в `.env` (по умолчанию)
- **Плюсы**: 
  - Масштабируемость
  - Легкое резервное копирование
  - Доступ из нескольких инстансов
  - S3-совместимое API
  - Автоматическая загрузка при первом запуске
- **Минусы**: Требует дополнительный сервис (но он уже в docker-compose)

#### Вариант B: Локальное хранение
- **Где**: `bot/data/OGE/` и `bot/data/EGE/`
- **Что хранится**: Те же файлы, но локально
- **Настройка**: `USE_MINIO=false` в `.env`
- **Плюсы**: Простота, быстрота для разработки
- **Минусы**: Не масштабируется, сложнее делать резервные копии

## 🔄 Автоматическая загрузка файлов

**По умолчанию MinIO включен**, и при первом запуске бот автоматически загрузит все файлы из `bot/data/` в MinIO.

Просто запустите:
```bash
docker-compose up -d
```

Бот проверит наличие файлов в MinIO и при необходимости загрузит их автоматически.

### Ручная загрузка (если нужно)

Если нужно перезагрузить файлы вручную:
```bash
# В контейнере
docker-compose exec bot python -m bot.utils.upload_to_minio

# Или локально
python -m bot.utils.upload_to_minio
```

## 🔄 Как переключиться на локальное хранение

Если нужно использовать локальное хранение вместо MinIO:

### Шаг 1: Отключить MinIO в `.env`
```env
USE_MINIO=false
```

### Шаг 2: Перезапустить бота
```bash
docker-compose restart bot
```

После этого бот будет использовать файлы из `bot/data/` локально.

## 🔍 Как это работает в коде

Код автоматически определяет, откуда брать файлы:

```python
# bot/services/storage.py
if self.use_minio:
    # Читаем из MinIO
    file_data = self.client.get_object(bucket, path)
else:
    # Читаем из локальной файловой системы
    with open(local_path, "rb") as f:
        file_data = f.read()
```

## 💡 Рекомендации

- **По умолчанию**: Используется MinIO (`USE_MINIO=true`) - это оптимально для большинства случаев
- **Для разработки**: Можно использовать локальное хранение (`USE_MINIO=false`) если не нужен MinIO
- **Для резервного копирования**: MinIO проще бэкапить (можно использовать `mc mirror`)
- **Автоматизация**: Файлы автоматически загружаются при первом запуске, не требуется ручная настройка
