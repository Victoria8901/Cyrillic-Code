# Описание функционала бота для подготовки к ОГЭ и ЕГЭ по русскому языку

## Общее описание
Telegram-бот для подготовки к ОГЭ и ЕГЭ по русскому языку. Бот помогает пользователям изучать теорию, решать задания и проходить тесты для проверки знаний.

## Основной функционал

### 1. Регистрация и авторизация
- **Регистрация при первом запуске**: При команде `/start` бот автоматически регистрирует пользователя в системе
- **Хранение профиля**: Сохранение имени пользователя, статистики прохождения заданий

### 2. Главное меню
- **Подготовка к ОГЭ**: Переход к выбору заданий ОГЭ (задания 2-9)
- **Подготовка к ЕГЭ**: Переход к выбору заданий ЕГЭ (задания 4-21) - *в разработке*
- **Мой профиль**: Просмотр статистики пользователя
- **Помощь**: Информация о работе бота

### 3. Подготовка к ОГЭ

#### 3.1 Выбор задания
- Пользователь выбирает номер задания (2-9)
- Для каждого задания доступна теория в формате PDF

#### 3.2 Решение заданий
- После изучения теории пользователь может решать задания
- Бот выдает случайное задание из базы (по 20 заданий на каждую тему)
- Пользователь вводит ответ
- Бот проверяет ответ и дает обратную связь:
  - При правильном ответе: "Молодец, продолжим?"
  - При неправильном ответе: "Неверно" с предложением попробовать еще раз
- После 10 правильных решений подряд бот предлагает пройти тест

#### 3.3 Тестирование
- Тест состоит из 10 случайных заданий по выбранной теме
- Пользователь отвечает на вопросы последовательно
- После завершения теста:
  - Если правильных ответов >= 80%: тема считается пройденной, статистика обновляется
  - Если правильных ответов < 80%: тема не засчитывается, предлагается пройти снова

### 4. Подготовка к ЕГЭ
- **Статус**: В процессе разработки
- **Планируемый функционал**: Аналогичен ОГЭ, но для заданий 4-21

### 5. Профиль пользователя
- Отображение имени пользователя
- Количество пройденных тем ОГЭ
- Количество пройденных тем ЕГЭ

### 6. Помощь
- Информация о том, как пользоваться ботом
- Инструкции по работе с заданиями и тестами

## Технические детали

### Структура данных
- **Задания ОГЭ**: Хранятся в текстовых файлах в папке `data/OGE/task{N}/`
- **Формат задания**: Текст задания + "Ответ:" + правильный ответ
- **Теория**: PDF-файлы для каждого задания

### База данных
- **Таблица users**: Хранение информации о пользователях
  - user_id (PK)
  - name
  - chat_id (уникальный)
  - count_oge (количество пройденных тем ОГЭ)
  - count_ege (количество пройденных тем ЕГЭ)
  - oge2, oge3, ..., oge9 (флаги прохождения каждой темы)
