### 🚀 Как запустить

1. Скопируйте `.env.example` в `.env` и заполните значения
2. Запустите `docker-compose up -d`
3. Проверьте логи: `docker-compose logs -f bot`

### 📊 Структура БД

```
users
├── user_id (PK)
├── chat_id (UNIQUE)
├── name
└── timestamps

oge_topics / ege_topics
├── topic_id (PK)
├── topic_number (UNIQUE)
└── description

user_oge_progress / user_ege_progress
├── progress_id (PK)
├── user_id (FK -> users)
├── topic_id (FK -> topics)
├── is_completed
├── correct_answers_count
└── timestamps

task_attempts
├── attempt_id (PK)
├── user_id (FK -> users)
├── task_id
├── task_type (OGE/EGE)
└── timestamps
```
